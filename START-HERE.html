1. Update Raiden

  1. Quit the old app from its tray menu.
  2. Extract this ZIP into a new writable folder. Keep the whole RaidenCompanion folder together.
  3. Run Start-Raiden.bat. It checks the dependencies and starts the overlay. If 0.12 already worked, keep your current Bionic, Qwen and Docker installations. Existing icon, hotkey, voice and model settings are reused.

The Settings title should end with 0.14. Keep your existing Qwen model; no model download or training is required.

2. Start your search service

  1. Install Docker Desktop for Windows AMD64, if needed.
  2. Start Docker Desktop using Linux containers and wait for its engine to be ready.
  3. Run Start-Search.bat. First run downloads the SearXNG software image. Keep Docker Desktop running while you use web guides.

This setup installs search software and uses disk space. Raiden does not save game guide files or use Bionic's paid web search. Stop-Search.bat stops the local search service.

3. Connect the two addresses

Keep your local Qwen server enabled in Bionic → Settings → Local Model API.

  • Raiden → Settings → AI: http://127.0.0.1:1234/v1, or your existing working address.
  • Settings → Guides → Guide workflow: Qwen + SearXNG + Trafilatura.
  • SearXNG address: http://127.0.0.1:8888. Click Test search connection.

Run Check-Connections.bat to test search, page reading and Qwen's actual tool calls on your PC. It prints results without saving a report.

Ask her for a build

Set Web → Auto or Always. Try Nicole build in Genshin Impact, then what about Mavuika, then her best weapon?. When changing games, name the new game. Try Hsin build in Wuthering Waves, then what about aemeth. Close spelling matches are disclosed when multiple live guide titles agree.

Genshin builds prefer the Genshin Impact Helper Team live roster and build fields. Equipment names, ranks, stats and conditions come from the source. Other games use the general search/read tools. This update fixes missing table values and collapsed item names, rejects navigation headings, and continues research when core build details are missing. Qwen can select complete evidence records, including unfamiliar equipment terms. No character-specific directory or model training is required.

Raiden checks build selections before displaying them, and keeps the character/game from your question rather than Qwen’s search wording. Answers appear in chat. Click a numbered citation to read its excerpt inside Raiden. Guide pages and chat context stay in RAM until you start a new chat or close the app. New questions get fresh searches.

Tool use needs several model turns and can be slow on the laptop. Keep Fast Qwen replies enabled. Try a 16K model context if memory permits. Readable guides must exist, and model/source errors remain possible.

Keep it in your game

Use borderless windowed mode. Click the icon or press Ctrl+Alt+R to open chat.

Drag the bottom-right grip to resize, or drag the heading to move the panel.

Screenshots go to your local vision model; search engines receive text queries.

Make her yours

Settings → Appearance changes the icon, opacity, size and shortcut.

Your speech settings are retained. The default system voice is a trial voice; a character voice requires your separate GPT-SoVITS setup and reference recording.

If it does not connect

Search unavailable: start Docker Desktop, run Start-Search.bat and test again. Qwen returns tool syntax: update Bionic's model runtime and run Check-Connections.bat.

The tool flow and UI have controlled automated tests. Your real Qwen model and Windows Docker setup need the included local check. README.md contains setup details, troubleshooting, limits and test commands.
